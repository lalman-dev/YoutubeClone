# 🎬 YouTube Clone

A responsive YouTube‑style application built with **React** and **Tailwind CSS**, featuring video playback, sidebar navigation, recommended videos, and channel details.  
Deployed on **Netlify** → [Live Demo](https://youtubeclonel.netlify.app/)

## ✨ Features
- 📺 **Video Playback** using YouTube Embed API  
- 📂 **Sidebar Navigation** with categories and subscriptions  
- 🎥 **Recommended Videos Section** with dynamic content  
- 👤 **Channel Details** including description, likes, and comments  
- 📱 **Responsive Layouts** for mobile, tablet, and desktop  
- 🎨 Styled with **TailwindCSS** + custom CSS for iframe responsiveness  

---

## 🛠 Tech Stack
- **Frontend:** React, TailwindCSS, JavaScript  
- **API:** YouTube Embed API  
- **Deployment:** Netlify  
- **Version Control:** Git + GitHub

## 🚀 Getting Started

1. Clone the repo and install dependencies:

```bash
git clone https://github.com/lalman-dev/YoutubeClone.git
cd YoutubeClone
```
2. Install dependencies
 ```bash
npm install
```

3. Set Up Environment Variables
Create a .env file in the root directory and add your YouTube API key:
```Env
VITE_YOUTUBE_API_KEY=your_api_key_here
```
⚠️ Keep your API key private. Do not commit .env to version control.

4. Run the Development Server
```bash
npm run dev
```

✅ Requirements
Node.js  ≥ 18
npm ≥ 9
Modern browser (Chrome, Firefox, Edge)
